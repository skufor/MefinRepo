# Security and publishing policy

MefinRepo is intended for lawful distribution of packages that the repository owner has permission to redistribute.

## Publishing rules

- Do not commit secrets, private keys, tokens, or personal data.
- Do not mirror third-party `.deb` files unless redistribution is permitted by the author or license.
- Prefer linking to the original upstream repository when redistribution rights are unclear.
- Packages should be scanned and tested before publication.
- Do not use this repository to distribute malware or packages intended to compromise devices or data.

If you find a security problem in this repository, open a private security report through GitHub if that feature is enabled for the repository; otherwise open an issue without including sensitive details.
